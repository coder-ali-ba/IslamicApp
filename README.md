# IlmHub 🕌

A modern Islamic learning platform for Quran, Tafseer,
Hadith, Islamic courses, live classes, teachers and Fatwa.

## Features
- Quran Reader
- Quran Translations
- Tafseer
- Hadith Collections
- Islamic Courses
- Live Classes
- Teachers
- Fatwa / Islamic Guidance

## Tech Stack
- Next.js
- TypeScript
- React
- Tailwind CSS
- Quran Foundation API
- Hadith API

## Getting Started
npm install
npm run dev
